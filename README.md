# ملعب جمعية الراكة — نظام الإيرادات

واجهة عربية RTL متجاوبة لتسجيل إيرادات الملعب مع صورة إيصال، باستخدام GitHub Pages وGoogle Apps Script وGoogle Sheets وGoogle Drive.

## مكونات المشروع
- \`index.html\`: تسجيل الدخول، نموذج الإيراد، عرض السجلات والإيصالات، وإدارة المستخدمين.
- \`apps-script/Code.gs\`: API للتحقق من الصلاحيات وتخزين الإيرادات والإيصالات.
- \`SETUP-AR.md\`: دليل الإعداد والنشر.

## تنبيه
يجب نشر Apps Script في حساب الجمعية وربط رابط /exec في الواجهة قبل الاستخدام. لم يتم إنشاء موارد Google أو نشر Web App تلقائيًا؛ ذلك يتطلب صلاحية في حساب Google. المجلد الخاص بالإيصالات يجب أن يبقى غير مشارك للعامة.
